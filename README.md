# GaksPack

Онлайн-каталог текстур для клиентского мода GaksPack. Проект поддерживает Gaksvord. Связь: [GurikTeam](https://t.me/GurikTeam).

Мод проверяет `index.json` при открытии меню и скачивает выбранные ZIP из `packs/`. После публикации изменений в ветке `main` обновлённые текстуры становятся доступны всем игрокам с модом.

## Добавление и замена текстур

Имя ZIP должно иметь вид `категория_название.zip`, например `crystal_blue.zip`. PNG для предпросмотра можно положить в `previews/` с таким же именем: `crystal_blue.png`.

- **Через сайт GitHub:** загрузите ZIP в `packs/`, а PNG в `previews/`. GitHub Actions проверит ZIP и обновит `index.json`.
- **Из этой папки на компьютере:** скопируйте ZIP и PNG в соответствующие папки, затем выполните `powershell -ExecutionPolicy Bypass -File .\publish-textures.ps1`. Скрипт проверит файлы, обновит индекс и отправит изменения в GitHub.
- **Из командной строки с названием для меню:** `python tools/stylesgaksvord.py publish-auto <pack.zip> <category> "Название" [preview.png]`.

Замена ZIP с тем же именем обновляет стиль у игроков после публикации. Удаление ZIP из `packs/` убирает стиль из каталога при следующем обновлении индекса. GitHub может кэшировать изменения несколько минут.

## Файлы

- `index.json` — список стилей, размеры и SHA-256 для проверки скачивания;
- `packs/` — ZIP-наборы ресурсов;
- `previews/` — изображения предпросмотра;
- `release/` — сборки мода и метаданные версий.

## Публикация версии мода

Положите JAR с именем `GaksPack-1.0.10+mc1.21.10.jar` в `release/mc/1.21.10/` (для другой версии Minecraft используйте соответствующую папку и суффикс имени). После загрузки в `main` GitHub Actions проверит целостность JAR, версию Minecraft, автора и контакт, затем обновит `version.json` с размером и SHA-256. Скрипт `python tools/sync_releases.py --write` выполняет ту же проверку локально.

Мод сверяет `version.json` только для установленной версии Minecraft. Новые текстуры появляются в каталоге автоматически; обновлённый JAR мода игроку нужно установить и перезапустить Minecraft.
