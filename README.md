# GaksPack

Облачный каталог стилей для клиентского мода **GaksPack**. Репозиторий поддерживает Gaksvord.
Мод читает `index.json` и загружает ZIP-набор, когда игрок выбирает стиль.

## Структура

- `index.json` — список стилей, их категории, контрольные суммы и превью;
- `packs/` — ZIP-ресурс-паки;
- `previews/` — изображения предпросмотра;
- `release/` — сборки мода для автообновления;
- `tools/stylesgaksvord.py` — публикация и удаление стилей через Git.

## Публикация стиля

Для публикации нужен Git-клон репозитория с правом записи:

```powershell
git clone https://github.com/Gaksvord/GaksPack.git
cd GaksPack
python tools/stylesgaksvord.py publish-auto <pack.zip> <category> <name> [preview.png]
```

Категории и ZIP с текстурами проверяются скриптом. Он обновляет `index.json`, считает SHA-256 и отправляет изменения в GitHub.

## Кредиты и лицензия

GaksPack обслуживает мод GaksPack и принадлежит проекту GaksPack / Gaksvord. Наборы текстур сохраняют имена и авторство, указанные их создателями.

Исходный код мода основан на Bauloo Styles by Bauloo0. В метаданных исходного мода указана лицензия **All Rights Reserved**; перед распространением изменённого кода необходимо получить разрешение правообладателя. Эта запись сохранена как атрибуция исходного проекта.
