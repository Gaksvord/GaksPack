# GaksPack

Онлайн-каталог текстур для клиентского мода GaksPack. Проект поддерживает Gaksvord. Связь: [GurikTeam](https://t.me/GurikTeam).

Мод проверяет `index.json` при открытии меню и скачивает выбранные ZIP из `packs/`. После публикации изменений в ветке `main` обновлённые текстуры становятся доступны всем игрокам с модом.

## Добавление и замена текстур

Имя ZIP должно иметь вид `категория_название.zip`, например `crystal_blue.zip`. Внутри ZIP папка `assets/` должна лежать в корне. PNG для предпросмотра можно положить в `previews/` с таким же именем: `crystal_blue.png`. Архив должен быть не больше 95 МиБ.

- **Через сайт GitHub:** откройте папку `packs/`, нажмите **Add file → Upload files**, перетащите ZIP и нажмите **Commit changes** в ветку `main`. Для картинки повторите это в `previews/`. GitHub Actions проверит ZIP, заменит описание в `pack.mcmeta` на `GaksPack textures - by gaksvord` и обновит `index.json`.
- **Из этой папки на компьютере:** скопируйте ZIP и PNG в соответствующие папки, затем выполните `powershell -ExecutionPolicy Bypass -File .\publish-textures.ps1`. Скрипт проверит файлы, обновит индекс и отправит изменения в GitHub.
- **Из командной строки с названием для меню:** `python tools/stylesgaksvord.py publish-auto <pack.zip> <category> "Название" [preview.png]`.

Для замены загрузите ZIP с тем же именем и подтвердите перезапись. Чтобы убрать стиль, откройте его ZIP в `packs/`, нажмите значок корзины **Delete this file** и подтвердите изменение; по желанию удалите одноимённый PNG из `previews/`. После завершения действия **Update texture catalog** список обновится у игроков при следующем открытии меню. GitHub может кэшировать изменения несколько минут.

## Текстуры мобов

Загрузите ZIP в `packs/` с именем `mob_имя_моба__название_стиля.zip`. Например, `mob_zombie__blue.zip`. Между именем моба и названием стиля нужны **два** подчёркивания. Внутри архива должны быть текстуры в `assets/minecraft/textures/entity/`, например `zombie/zombie.png`. Каталог запоминает точные пути из ZIP: если положить туда текстуры нескольких мобов, стиль затронет их всех. Для отдельной настройки каждого моба делайте отдельный ZIP.

После загрузки GitHub Actions сам создаст категорию «Zombie» в разделе «Мобы» и добавит стиль. Отдельную картинку можно загрузить как `previews/mob_zombie__blue.png`. Для другого моба замените `zombie` на его имя в пути Minecraft. Чешуйница (`silverfish`) и фантом (`phantom`) отключены.

## Файлы

- `index.json` — список стилей, размеры и SHA-256 для проверки скачивания;
- `packs/` — ZIP-наборы ресурсов;
- `previews/` — изображения предпросмотра;
- `release/` — сборки мода и метаданные версий.

## Публикация версии мода

Положите JAR с именем `GaksPack-1.0.10+mc1.21.10.jar` в `release/mc/1.21.10/` (для другой версии Minecraft используйте соответствующую папку и суффикс имени). После загрузки в `main` GitHub Actions проверит целостность JAR, версию Minecraft, автора и контакт, затем обновит `version.json` с размером и SHA-256. Скрипт `python tools/sync_releases.py --write` выполняет ту же проверку локально.

Мод сверяет `version.json` только для установленной версии Minecraft. Новые текстуры появляются в каталоге автоматически; обновлённый JAR мода игроку нужно установить и перезапустить Minecraft.
