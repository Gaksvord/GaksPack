# Целые ресурс-паки

Помести ZIP ресурс-пака в эту папку. Имя файла должно состоять из строчных латинских букв, цифр и знака подчёркивания, например `my_pack.zip`. В архиве должен быть `pack.mcmeta` в корне; размер архива — не более 95 МиБ.

После загрузки в ветку `main` GitHub Actions проверит архив и обновит `index.json`. Мод получит обновлённый каталог и позволит скачать и применить пак целиком. Для изменения отображаемого названия можно поправить поле `name` в `index.json`: скрипт сохранит его при последующих обновлениях архива. Для удаления пака удали его ZIP из этой папки; каталог обновится автоматически.

Публикуй только паки, на распространение которых у тебя есть права.
